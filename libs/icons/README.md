# icons

This library was generated with [Nx](https://nx.dev).

`@dynamong/icons` holds shared SVG icon components used internally by other
`@dynamong/*` components (e.g. `DynamoCheckIcon`, used by `@dynamong/checkbox`).
It is deliberately scoped to a small, as-needed set of icons rather than a full
icon font/library port — see the root README's "Known simplifications".

## Running unit tests

Run `nx test icons` to execute the unit tests.
