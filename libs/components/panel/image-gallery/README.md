# @dynamong/image-gallery

A main image viewer with a thumbnail strip and a fullscreen lightbox — for
browsing a fixed array of images (product shots, a media set), as opposed to
Carousel's arbitrary projected slide content.

## Usage

```html
<dg-image-gallery
  [images]="productImages"
  [(activeIndex)]="index"
  aspectRatio="square"
  ariaLabel="Product photos"
/>
```

```ts
protected readonly index = signal(0);
protected readonly productImages: DynamoGalleryImage[] = [
  { src: '/img/full-1.jpg', thumbnailSrc: '/img/thumb-1.jpg', alt: 'Front view' },
];
```

## Inputs

| Input              | Type                              | Default     | Description                                                                                                                   |
| ------------------ | --------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `images`           | `DynamoGalleryImage[]` (required) | —           | Each entry: `src`, optional `thumbnailSrc` (falls back to `src`), `alt`, optional `caption` (shown under the lightbox image). |
| `activeIndex`      | `number` (model)                  | `0`         | Two-way bindable; the currently shown image's index.                                                                          |
| `loop`             | `boolean`                         | `true`      | Whether prev/next wrap around at the ends. When `false`, the arrow buttons disable at the boundaries instead.                 |
| `aspectRatio`      | `'square' \| 'video' \| 'wide'`   | `'video'`   | Aspect ratio of the main viewport.                                                                                            |
| `showThumbnails`   | `boolean`                         | `true`      | Shows the thumbnail strip (only when there's more than one image).                                                            |
| `showArrows`       | `boolean`                         | `true`      | Shows the main viewport's prev/next buttons (only when there's more than one image).                                          |
| `autoPlay`         | `boolean`                         | `false`     | Starts an auto-advance timer. Also reveals the play/pause toggle button. Paused automatically while the lightbox is open.     |
| `autoPlayInterval` | `number`                          | `5000`      | Milliseconds between auto-advances.                                                                                           |
| `lightboxOpen`     | `boolean` (model)                 | `false`     | Two-way bindable; open the fullscreen lightbox programmatically, or read whether it's open.                                   |
| `ariaLabel`        | `string \| undefined`             | `undefined` | Falls back to `'Image gallery'` on the viewport's `aria-label`.                                                               |

## Outputs

| Output               | Payload   | Fires when                                                                                                                       |
| -------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `activeIndexChange`  | `number`  | `activeIndex` changes (auto-generated by `model()`) — from arrows, thumbnail clicks, keyboard navigation, or autoplay.           |
| `lightboxOpenChange` | `boolean` | `lightboxOpen` changes (auto-generated by `model()`) — from the main image click/Enter, close button, backdrop click, or Escape. |

## Accessibility

- The main image is a `<button>` that opens the lightbox, labeled `"View fullscreen: {alt}, N of M"`.
- Thumbnails form a `role="tablist"`/`role="tab"` group with roving tabindex and `ArrowLeft`/`ArrowRight`/`Home`/`End` navigation (automatic activation).
- The lightbox is `role="dialog"` with `aria-modal="true"`, a focus trap (via `DynamoFocusTrapService`, the same mechanism Dialog uses), focus moved into the panel on open and restored to the previously-focused element on close, and `Escape` to close.
- A broken image (fires the native `error` event) is replaced with an inline fallback icon rather than left as a broken-image glyph, tracked per index so the main image, its thumbnail, and its lightbox view all fall back independently.

## Design notes

`showArrows` and `autoPlay`/`autoPlayInterval` mirror Carousel's own
autoplay: pauses on pointer hover or focus-within, plus an explicit
play/pause toggle — also pauses while the lightbox is open here.
`lightboxOpen` is externally bindable, so a consumer can open the fullscreen
view programmatically. A few things were considered and left out: a
paginated N-visible-with-nav-arrows mode for the thumbnail strip (it already
handles overflow via horizontal scroll — adding a second navigation model
would be a disproportionate redesign for little gain); separate dot
indicators (redundant — the thumbnail strip already serves as the position
indicator); and a configurable thumbnail-strip/indicator position
(top/bottom/left/right layout variants — disproportionate redesign with no
existing precedent).
