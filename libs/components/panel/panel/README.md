# @dynamong/panel

A single standalone collapsible content section — the gap between Card (a
plain content container with no collapse) and Accordion (which coordinates
*multiple* mutually-exclusive or multi-open panels).

## Usage

```html
<dg-panel header="Advanced settings" [collapsible]="true" [(collapsed)]="isCollapsed">
  <p>Panel body content, projected via ng-content.</p>
</dg-panel>
```

```ts
protected readonly isCollapsed = signal(true);
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `header` | `string` | `''` | Header text. When empty and `collapsible` is `false`, no header row is rendered at all. |
| `variant` | `'elevated' \| 'outlined' \| 'filled'` | `'elevated'` | Visual style of the panel container. |
| `collapsible` | `boolean` | `false` | Renders the header as a toggle button and enables collapse/expand. |
| `collapsed` | `boolean` (model) | `false` | Two-way bindable. Only meaningful when `collapsible` is `true`. |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `collapsedChange` | `boolean` | `collapsed` changes (auto-generated by `model()`) — the header toggle is clicked. |

## Accessibility

- When `collapsible`, the header is a `<button aria-expanded aria-controls>` toggling the content region.
- The content region is `role="region"`, labeled via `aria-labelledby` pointing at the header (whenever a header or collapsible toggle is present).
- Collapse/expand is a pure CSS grid-rows transition (0fr/1fr), the same technique used by Accordion.

## Tier / dependencies

- `tier:0`. Peer dependencies: `@angular/cdk`, `@dynamong/core`, `@dynamong/utils`.
