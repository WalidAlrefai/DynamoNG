# @dynamong/accordion

A vertically stacked set of collapsible panels — single- or multiple-expand
— with roving-focus arrow-key navigation between headers. Panels are
declared as child `<dg-accordion-panel>` content rather than an `items`
input.

## Usage

```html
<dg-accordion [(value)]="expandedIds" [multiple]="true" ariaLabel="FAQ">
  <dg-accordion-panel value="p1" header="What is DynamoNG?">
    Content for the first panel.
  </dg-accordion-panel>
  <dg-accordion-panel value="p2" header="Getting started" [disabled]="isLocked">
    Content for the second panel.
  </dg-accordion-panel>
</dg-accordion>
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `value` | `string \| string[] \| undefined` (model) | `undefined` | Two-way bindable. A single string (or `undefined`) when `multiple` is `false`; a `string[]` when `multiple` is `true`. |
| `multiple` | `boolean` | `false` | `false`: expanding a panel collapses any other. `true`: panels expand/collapse independently. |
| `ariaLabel` | `string \| undefined` | `undefined` | |

### `<dg-accordion-panel>` inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `value` | `string` (required) | — | Matched against the accordion's `value`. |
| `header` | `string` (required) | — | Header button text. |
| `disabled` | `boolean` | `false` | |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `valueChange` | `string \| string[] \| undefined` | `value` changes (auto-generated by `model()`), including automatic pruning when an expanded panel's `value` disappears or becomes `disabled`. |

## Accessibility

- Each header is a real `<button>` with `aria-expanded`/`aria-controls`; each content region is `role="region"` with `aria-labelledby` pointing at its header, mounted lazily on first expand and kept mounted (hidden, not destroyed) afterward.
- Keyboard: `ArrowDown`/`ArrowUp` move focus between headers (wrapping, skipping disabled ones), `Home`/`End` jump to the first/last enabled header.

## Tier / dependencies

- `tier:0`. Peer dependencies: `@dynamong/core`, `@dynamong/utils` (plus Angular core/CDK).
