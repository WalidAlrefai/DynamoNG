# @dynamong/panel-menu

A vertical, always-visible nested action menu that expands and collapses
in place — no overlay/popup, unlike Menu, Tiered Menu, or Menubar. Use it
for a persistent in-page navigation/action tree (e.g. a sidebar), as
opposed to Tree's value-selection semantics or the overlay menus' popup
dropdowns.

## Usage

```html
<dg-panel-menu
  [items]="items"
  [(expandedPaths)]="expanded"
  ariaLabel="Settings"
  (itemSelect)="onItemSelect($event)"
/>
```

```ts
protected onItemSelect(item: DynamoPanelMenuItem): void { ... }
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `items` | `DynamoPanelMenuItem[]` (required) | — | Each entry: `label`, optional `disabled`, optional `children` (nested items), optional `command` (invoked when a leaf item is committed). Items carry no `id` — nodes are tracked by structural path (dash-joined child-index chain, e.g. `"0-2-1"`). |
| `expandedPaths` | `string[]` (model) | `[]` | Which node paths are currently expanded. |
| `ariaLabel` | `string \| undefined` | `undefined` | |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `expandedPathsChange` | `string[]` | `expandedPaths` changes (auto-generated by `model()`). |
| `itemSelect` | `DynamoPanelMenuItem` | A leaf item (no `children`) is committed — click, or Enter/Space via the row's native `<button>` behavior. Never fires for a branch row (branches only toggle expand/collapse). The item's own `command()`, if provided, is also invoked. |

## Accessibility

- Root is a `<nav>`. Deliberately avoids both `role="tree"`/`"treeitem"` (implies selectable nodes, which these aren't) and `role="menu"`/`"menuitem"` (implies a popup with escape-to-close semantics, which doesn't apply to an always-visible panel). Instead, each row is a plain `<button aria-expanded aria-controls>` (branches) or `<button>` (leaves), the same shape as an Accordion header, with `role="group"` wrapping each children list.
- Roving tabindex across the flattened list of *visible* entries (collapsed branches' children are skipped entirely, not just hidden).
- Keyboard: `ArrowUp`/`ArrowDown` move through visible rows (wrapping), `Home`/`End` jump to the first/last enabled row, `ArrowRight` expands a collapsed branch or descends into an expanded one, `ArrowLeft` collapses an expanded branch or ascends to its parent. `Enter`/`Space` are handled natively by each row's `<button>` (not re-handled in the keydown handler, to avoid double-firing).
