# forms-radio

This library was generated with [Nx](https://nx.dev).

`@dynamong/radio` styles a single native `<input type="radio">`. There is no
`RadioGroup` container component — group siblings by giving them the same
`name` input, same as plain HTML. See `DynamoRadio`'s `checked` doc comment
for the recommended split-binding pattern (`[checked]` + `(checkedChange)`)
when driving a group from a single shared selection signal.

## Running unit tests

Run `nx test forms-radio` to execute the unit tests.
