# @dynamong/toggle-button

A single two-state pressed/unpressed button — a thin wrapper around
`dg-button` that manages `aria-pressed` and swaps variant/severity while
pressed. Use it standalone for one on/off toggle (e.g. "bold", "favorite");
for a connected group of options, use Select Button instead.

## Usage

```html
<dg-toggle-button [(pressed)]="isBold" ariaLabel="Bold">
  <dg-icon-bold />
</dg-toggle-button>
```

## Inputs

| Input       | Type                     | Default     | Description                                                                                                    |
| ----------- | ------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------- |
| `pressed`   | `boolean` (model)        | `false`     | Two-way bindable pressed state.                                                                                |
| `disabled`  | `boolean`                | `false`     |                                                                                                                |
| `size`      | `DynamoToggleButtonSize` | `'md'`      |                                                                                                                |
| `severity`  | `DynamoSeverity`         | `'primary'` | Applied only while pressed (solid fill). Unpressed always renders a neutral outline, regardless of this input. |
| `ariaLabel` | `string \| undefined`    | `undefined` | Required when there's no visible text content (e.g. an icon-only toggle).                                      |

## Outputs

| Output          | Payload   | Fires when                                                                                        |
| --------------- | --------- | ------------------------------------------------------------------------------------------------- |
| `pressedChange` | `boolean` | `pressed` changes (auto-generated by `model()`) — toggles on click, provided `disabled` is false. |

## Accessibility

- Delegates to `dg-button`, which renders `aria-pressed` reflecting `pressed()` — the standard native toggle-button pattern, no extra role needed.

## Tier / dependencies

- `tier:2`. Peer dependencies: `@dynamong/button`.

## Running unit tests

Run `nx test forms-toggle-button` to execute the unit tests.
