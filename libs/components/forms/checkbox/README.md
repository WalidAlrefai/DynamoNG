# @dynamong/checkbox

A styled checkbox with two-way bound checked state and an indeterminate
visual.

## Usage

```html
<dg-checkbox [(checked)]="agreed" [indeterminate]="isPartial()" size="md">
  I agree to the terms
</dg-checkbox>
```

```ts
protected readonly agreed = signal(false);
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `checked` | `boolean` (model) | `false` | Two-way bindable: `<dg-checkbox [(checked)]="value">`. |
| `indeterminate` | `boolean` | `false` | Visual-only mixed state; does not affect `checked`. |
| `disabled` | `boolean` | `false` | |
| `size` | `DynamoSize` | `'md'` | |
| `ariaLabel` | `string \| undefined` | `undefined` | Accessible name for the native checkbox when no visible label content is projected. |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `checkedChange` | `boolean` | `checked` changes (auto-generated by `model()`). |

## Accessibility

- Renders a visually-hidden native `<input type="checkbox">` (`sr-only`) under a styled label/box, so native keyboard and click semantics (Space toggles, clicking the label toggles) come for free.
- `aria-checked="mixed"` is set while `indeterminate` is true.
