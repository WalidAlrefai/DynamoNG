# @dynamong/rating

A star rating input — click a star or use the arrow keys to set a value
from `0` to `max`, with a hover preview. Renders as a single `role="slider"`
widget rather than N separately-focusable stars. Implements
`ControlValueAccessor`, so it works with `formControl`/`ngModel` in
addition to `[(value)]`.

## Usage

```html
<dg-rating [(value)]="stars" [max]="5" ariaLabel="Rate this product" />
```

## Inputs

| Input       | Type                  | Default     | Description                                                                         |
| ----------- | --------------------- | ----------- | ----------------------------------------------------------------------------------- |
| `max`       | `number`              | `5`         | Number of stars rendered.                                                           |
| `value`     | `number` (model)      | `0`         | Two-way bindable; also driven by Angular forms via `writeValue`. `0` means unrated. |
| `readOnly`  | `boolean`             | `false`     | Displays the current value but blocks hover preview, clicks, and keyboard changes.  |
| `disabled`  | `boolean` (model)     | `false`     | Two-way bindable; also driven by Angular forms via `setDisabledState`.              |
| `size`      | `DynamoSize`          | `'md'`      |                                                                                     |
| `ariaLabel` | `string \| undefined` | `undefined` | Defaults to `'Rating'` when unset.                                                  |

## Outputs

| Output           | Payload   | Fires when                                                                                                                                                                          |
| ---------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `valueChange`    | `number`  | `value` changes (auto-generated by `model()`) — from clicking a star (clicking the already-set star resets to `0`), or `ArrowRight`/`ArrowUp`/`ArrowLeft`/`ArrowDown`/`Home`/`End`. |
| `disabledChange` | `boolean` | `disabled` changes (auto-generated by `model()`).                                                                                                                                   |

## Accessibility

- A single `role="slider"` root carries `aria-valuenow`/`aria-valuemin="0"`/`aria-valuemax`/`aria-readonly`/`aria-disabled` — the whole group is one focusable control, not N stars.
- Keyboard: `ArrowRight`/`ArrowUp` increments, `ArrowLeft`/`ArrowDown` decrements, `Home` resets to `0`, `End` jumps to `max`.
- Individual stars are plain non-focusable `<span>`s (not `<button>`s) — a star isn't independently operable, so it's exposed only through the group's own value.

## Tier / dependencies

- `tier:0`. Peer dependencies: `@angular/forms` (`ControlValueAccessor`).
