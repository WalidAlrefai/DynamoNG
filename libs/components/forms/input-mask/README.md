# @dynamong/input-mask

A text input that enforces a fixed character pattern as the user types —
phone numbers, dates, codes — auto-inserting literal characters and
rejecting keystrokes that don't fit the current slot.

## Usage

```html
<dg-input-mask
  mask="(999) 999-9999"
  [(value)]="phone"
  placeholder="(555) 555-5555"
  ariaLabel="Phone number"
/>
```

Mask syntax: `9` = digit, `a` = letter, `*` = alphanumeric, any other
character is a literal that's auto-inserted (e.g. the `(`, `)`, ` `, `-`
above).

While focused, unfilled slots show as `slotChar` (default `_`) so the whole
shape of the mask is visible up front, e.g. typing `"555"` into the phone
mask above displays `"(555) ___-____"`. The buffer disappears again on
blur, leaving only the real matched value (or nothing at all, if
`autoClear` clears an incomplete one).

## Inputs

| Input         | Type                  | Default     | Description                                                                                                                                                                                             |
| ------------- | --------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mask`        | `string` (required)   | —           | The mask pattern, e.g. `"(999) 999-9999"`.                                                                                                                                                              |
| `size`        | `DynamoInputMaskSize` | `'md'`      |                                                                                                                                                                                                         |
| `placeholder` | `string`              | `''`        |                                                                                                                                                                                                         |
| `invalid`     | `boolean`             | `false`     |                                                                                                                                                                                                         |
| `ariaLabel`   | `string \| undefined` | `undefined` | Accessible name for the input when no visible `<label>` wraps it.                                                                                                                                       |
| `disabled`    | `boolean` (model)     | `false`     | Two-way bindable; also driven by Angular forms via `setDisabledState`.                                                                                                                                  |
| `readOnly`    | `boolean`             | `false`     | HTML `readonly` semantics — value stays visible and focusable/tabbable but not editable. Unlike `disabled`, doesn't remove the control from the tab order or dim it.                                    |
| `slotChar`    | `string`              | `'_'`       | Placeholder character shown for each not-yet-filled slot while focused.                                                                                                                                 |
| `autoClear`   | `boolean`             | `true`      | Reverts an incomplete value back to empty on blur, so a half-filled mask is never left looking like meaningful data.                                                                                    |
| `value`       | `string` (model)      | `''`        | Two-way bindable; also driven by Angular forms via `writeValue`/`ControlValueAccessor`. An externally-set value that doesn't already match the mask is re-masked on write, not just on user keystrokes. |

## Outputs

| Output           | Payload   | Fires when                                                                                                                        |
| ---------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `valueChange`    | `string`  | `value` changes (auto-generated by `model()`) — on masked keystroke, paste, or backspace/delete, as well as programmatic changes. |
| `disabledChange` | `boolean` | `disabled` changes (auto-generated by `model()`).                                                                                 |
| `complete`       | `string`  | Once, on the transition into a fully-filled mask — not on every keystroke while it stays complete.                                |

## Accessibility

- A native `<input>` under the hood, so it picks up standard text-field
  semantics automatically; pair with a `<label>` or set `ariaLabel` when no
  visible label wraps it.
- Backspace/Delete skip over literal characters to clear the nearest real
  placeholder rather than deleting the literal itself; paste is masked and
  invalid characters are silently rejected rather than aborting the edit.

## Tier / dependencies
