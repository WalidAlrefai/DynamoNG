# @dynamong/pagination

A page-number bar for paginated data — collapsing page-number buttons with
an ellipsis, previous/next navigation, and an optional rows-per-page
selector. Its `page`/`pageSize` models are designed to compose naturally
with `DynamoTable`'s own.

## Usage

```html
<dg-pagination
  [totalItems]="totalRows()"
  [(page)]="page"
  [(pageSize)]="pageSize"
  [pageSizeOptions]="[10, 25, 50, 100]"
/>
```

```ts
protected page = signal(1);
protected pageSize = signal(10);
```

## Inputs

| Input                  | Type                   | Default             | Description                                                                                                                                                                     |
| ---------------------- | ---------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `totalItems`           | `number` (required)    | —                   | Total row count across all pages.                                                                                                                                               |
| `page`                 | `number` (model)       | `1`                 | Two-way bindable, 1-indexed. The _displayed_ current page is clamped into `[1, pageCount]`; `page()` itself is only ever written by explicit interaction (never by a computed). |
| `pageSize`             | `number` (model)       | `10`                | Two-way bindable rows-per-page.                                                                                                                                                 |
| `pageSizeOptions`      | `number[]`             | `[10, 25, 50, 100]` | Options shown in the rows-per-page `<dg-select>`.                                                                                                                               |
| `showPageSizeSelector` | `boolean`              | `true`              |                                                                                                                                                                                 |
| `maxVisiblePages`      | `number`               | `5`                 | Soft target for how many page-number buttons show before collapsing to an ellipsis.                                                                                             |
| `size`                 | `DynamoPaginationSize` | `'md'`              |                                                                                                                                                                                 |
| `disabled`             | `boolean`              | `false`             |                                                                                                                                                                                 |
| `ariaLabel`            | `string`               | `'Pagination'`      |                                                                                                                                                                                 |

## Outputs

| Output           | Payload  | Fires when                                                                                              |
| ---------------- | -------- | ------------------------------------------------------------------------------------------------------- |
| `pageChange`     | `number` | `page` changes (auto-generated by `model()`).                                                           |
| `pageSizeChange` | `number` | `pageSize` changes (auto-generated by `model()`) — changing rows-per-page also resets `page` back to 1. |

## Accessibility

- `<nav>` landmark carrying `ariaLabel`; an `aria-live="polite"` summary region announces the visible range (e.g. "Showing 1-10 of 42", or "No results" when `totalItems` is 0).
- Previous/next and page-number controls are `<dg-button>`s with descriptive labels ("Previous page", "Next page", "Page N"); the active page button carries `aria-current="page"`.

## Tier / dependencies

- `tier:2`. Peer dependencies: `@dynamong/button`, `@dynamong/select`.
