# @dynamong/switch

A boolean toggle switch styled around a visually-hidden native
`<input type="checkbox" role="switch">`.

## Usage

```html
<dg-switch [(checked)]="notificationsEnabled">Enable notifications</dg-switch>
```

```ts
protected notificationsEnabled = signal(false);
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `checked` | `boolean` (model) | `false` | Two-way bindable. |
| `disabled` | `boolean` | `false` | |
| `size` | `DynamoSwitchSize` | `'md'` | |
| `ariaLabel` | `string \| undefined` | `undefined` | Accessible name for the native switch when no visible label content is projected. |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `checkedChange` | `boolean` | `checked` changes (auto-generated by `model()`). |

## Accessibility

- Renders a native `<input type="checkbox" role="switch">` (visually hidden via `sr-only`) inside a `<label>`, with `aria-checked` kept in sync — native checkbox keyboard behavior (Space to toggle) and label association come from the browser for free.

## Tier / dependencies

- `tier:0`. Peer dependencies: none beyond Angular core/CDK.
