# @dynamong/password

A password input with a show/hide toggle and an optional strength meter —
plugs into Angular forms as a `ControlValueAccessor`.

## Usage

```html
<dg-password
  [(value)]="password"
  [showStrengthMeter]="true"
  placeholder="Enter a password"
  ariaLabel="Password"
/>
```

## Inputs

| Input               | Type                  | Default     | Description                                                                                                                                                                                       |
| ------------------- | --------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `size`              | `DynamoSize`          | `'md'`      |                                                                                                                                                                                                   |
| `placeholder`       | `string`              | `''`        |                                                                                                                                                                                                   |
| `invalid`           | `boolean`             | `false`     |                                                                                                                                                                                                   |
| `ariaLabel`         | `string \| undefined` | `undefined` | Accessible name for the input when no visible `<label>` wraps it.                                                                                                                                 |
| `showStrengthMeter` | `boolean`             | `false`     | Renders a `@dynamong/progress` bar + label below the field, driven by a built-in crude strength heuristic (length thresholds + character-class variety) — a visual nudge, not a security control. |
| `disabled`          | `boolean` (model)     | `false`     | Two-way bindable; also driven by Angular forms via `setDisabledState`.                                                                                                                            |
| `readOnly`          | `boolean`             | `false`     | HTML `readonly` semantics — value stays visible and focusable/tabbable but not editable. Unlike `disabled`, doesn't remove the control from the tab order or dim it.                              |
| `value`             | `string` (model)      | `''`        | Two-way bindable; also driven by Angular forms via `writeValue`.                                                                                                                                  |

## Outputs

| Output           | Payload   | Fires when                                                          |
| ---------------- | --------- | ------------------------------------------------------------------- |
| `valueChange`    | `string`  | `value` changes (auto-generated by `model()`) — on every keystroke. |
| `disabledChange` | `boolean` | `disabled` changes (auto-generated by `model()`).                   |

## Accessibility

- A native `<input type="password">`/`type="text"` (toggled by the visibility
  button) with `aria-invalid`, `aria-readonly`, `aria-label`, and
  `aria-describedby` pointing at the strength meter when `showStrengthMeter`
  is on.
- The show/hide toggle is a `<button type="button">` with an `aria-label` of
  `'Show password'`/`'Hide password'` that updates with its state.
- The strength meter reuses `@dynamong/progress`'s own `ariaLabel` (e.g.
  `"Password strength: weak"`).

## Tier / dependencies

- `tier:1`. Peer dependencies: `@angular/forms` (`ControlValueAccessor`), `@dynamong/progress`.
