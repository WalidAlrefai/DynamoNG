# @dynamong/fieldset

A bordered, `<legend>`'d form section built on the real native
`<fieldset>`/`<legend>` elements, with an optional collapsible mode.

## Usage

```html
<dg-fieldset
  legend="Shipping address"
  [collapsible]="true"
  [(collapsed)]="addressCollapsed"
>
  <dg-input-text [(value)]="street" placeholder="Street" />
</dg-fieldset>
```

```ts
protected addressCollapsed = signal(false);
```

## Inputs

| Input         | Type              | Default | Description                                                                                                                              |
| ------------- | ----------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `legend`      | `string`          | `''`    |                                                                                                                                          |
| `collapsible` | `boolean`         | `false` |                                                                                                                                          |
| `collapsed`   | `boolean` (model) | `false` | Two-way bindable. Only meaningful when `collapsible` is `true`.                                                                          |
| `disabled`    | `boolean`         | `false` | Maps to the native `<fieldset disabled>` attribute — disables every descendant form control without this component touching any of them. |

## Outputs

| Output            | Payload   | Fires when                                                                                     |
| ----------------- | --------- | ---------------------------------------------------------------------------------------------- |
| `collapsedChange` | `boolean` | `collapsed` changes (auto-generated by `model()`), i.e. the collapse toggle button is clicked. |

## Accessibility

- Built on real `<fieldset>`/`<legend>` elements, so assistive tech already gets a native grouping relationship for free — the collapsible content region deliberately does not layer `role="region"`/`aria-labelledby` on top, which would just duplicate that native semantics. The collapse toggle is a `<button aria-expanded>` with `aria-controls` pointing at the content region.

## Tier / dependencies

- `tier:0`. Peer dependencies: none beyond Angular core/CDK.
