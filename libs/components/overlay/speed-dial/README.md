# @dynamong/speed-dial

A floating action button that fans out a set of secondary action buttons in a
line or an arc when opened, with full keyboard navigation and optional
open-on-hover.

## Usage

```html
<dg-speed-dial
  [actions]="actions"
  [(open)]="isOpen"
  type="circle"
  direction="up"
  ariaLabel="Quick actions"
  (actionSelect)="onActionSelect($event)"
/>
```

```ts
protected onActionSelect(action: DynamoSpeedDialAction): void { ... }
```

## Inputs

| Input         | Type                                 | Default        | Description                                                                                                                                   |
| ------------- | ------------------------------------ | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `actions`     | `DynamoSpeedDialAction[]` (required) | —              | The fanned-out actions. Each has `label`, optional `icon` (falls back to the label's first letter), `disabled`, `command`.                    |
| `direction`   | `DynamoSpeedDialDirection`           | `'up'`         | Which way the actions fan out: `'up' \| 'down' \| 'left' \| 'right'`.                                                                         |
| `type`        | `DynamoSpeedDialType`                | `'linear'`     | Layout: a straight line (`'linear'`) or an arc (`'circle'`, `'semi-circle'`, `'quarter-circle'`).                                             |
| `open`        | `boolean` (model)                    | `false`        | Two-way bindable open state.                                                                                                                  |
| `openOnHover` | `boolean`                            | `false`        | Opens on trigger hover instead of requiring a click; closes after a short delay once the pointer leaves both the trigger and the action list. |
| `radius`      | `number`                             | `90`           | Arc radius in px, for the non-`linear` types.                                                                                                 |
| `gap`         | `number`                             | `56`           | Spacing in px between successive actions, for the `linear` type.                                                                              |
| `ariaLabel`   | `string`                             | `'Speed dial'` |                                                                                                                                               |
| `disabled`    | `boolean`                            | `false`        | Disables the trigger entirely (also suppresses hover-open).                                                                                   |

## Outputs

| Output         | Payload                 | Fires when                                                                                                                                   |
| -------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `openChange`   | `boolean`               | `open` changes (auto-generated by `model()`).                                                                                                |
| `actionSelect` | `DynamoSpeedDialAction` | A user activates an enabled action (click or `Enter`/`Space`) — fires before the action's own `command` callback and before the dial closes. |

## Accessibility

- The trigger is a real `<button>` with `aria-haspopup="true"`, `aria-expanded`, `aria-controls`. The action list is `role="menu"` with `role="menuitem"` action buttons (`tabindex="-1"`, moved with real DOM focus via the arrow keys while open).
- Keyboard on the trigger: `Enter`/`Space` toggles open (and focuses the first enabled action when opening); any arrow key opens the dial and focuses the first enabled action.
- Keyboard on the actions: arrow keys move focus and wrap, `Home`/`End` jump to the first/last enabled action, `Escape` closes and refocuses the trigger, `Tab` closes.
- A click outside the widget also closes it.
