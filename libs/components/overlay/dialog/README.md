# @dynamong/dialog

A modal dialog with a backdrop and focus trap, rendered in place in the
host template (no overlay service). Use it for confirmations and focused,
blocking forms; for a viewport-edge-anchored panel, use Drawer instead.

## Usage

```html
<dg-dialog [(open)]="isOpen" title="Delete item?" size="sm">
  <p>This can't be undone.</p>
</dg-dialog>
```

## Inputs

| Input                  | Type                  | Default     | Description                                                                                                                   |
| ---------------------- | --------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `open`                 | `boolean` (model)     | `false`     | Two-way bindable.                                                                                                             |
| `title`                | `string \| undefined` | `undefined` | Rendered as an `<h2>` header with a close button. Omit for a chrome-less panel (pair with `ariaLabel` for accessible naming). |
| `size`                 | `DynamoDialogSize`    | `'md'`      |                                                                                                                               |
| `closeOnBackdropClick` | `boolean`             | `true`      |                                                                                                                               |
| `closeOnEscape`        | `boolean`             | `true`      |                                                                                                                               |
| `ariaLabel`            | `string \| undefined` | `undefined` | Required when no `title` is set, so the dialog has an accessible name.                                                        |

The component also exposes a public `close()` method for imperative
closing, e.g. from a button inside the projected content.

## Outputs

| Output       | Payload   | Fires when                                                                                                                     |
| ------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `openChange` | `boolean` | `open` changes (auto-generated by `model()`) — from a backdrop click, `Escape`, the header close button, or a `.close()` call. |

## Accessibility

- `role="dialog"` with `aria-modal="true"`, labelled via `aria-label` or (when only `title` is set) `aria-labelledby` pointing at the title's `id`; the backdrop is `aria-hidden`.
- A focus trap (via `@dynamong/core/a11y`) activates on open, moves focus into the panel, and restores focus to whatever was previously focused when the dialog closes.
- `Escape` closes when `closeOnEscape` is true (default); clicking the backdrop closes when `closeOnBackdropClick` is true (default).

## Tier / dependencies

- `tier:0`. Peer dependencies: none beyond Angular core/CDK.
