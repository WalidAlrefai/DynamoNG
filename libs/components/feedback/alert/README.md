# @dynamong/alert

An inline, severity-colored message banner with an optional title and a
self-dismiss close button — for page- or form-level status messages that
stay in the flow (not a toast).

## Usage

```html
<dg-alert severity="danger" title="Something went wrong" [closable]="true" [(visible)]="showError">
  Couldn't save your changes. Please try again.
</dg-alert>
```

```ts
protected readonly showError = signal(true);
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `severity` | `DynamoSeverity` | `'info'` | `'primary' \| 'secondary' \| 'success' \| 'info' \| 'warning' \| 'danger'`. Drives the icon and color. |
| `title` | `string \| undefined` | `undefined` | Optional bold heading above the projected message content. |
| `closable` | `boolean` | `false` | Shows a dismiss button that sets `visible` to `false`. |
| `visible` | `boolean` (model) | `true` | Two-way bindable; the component self-dismisses (sets this to `false`) when `closable` and the close button is clicked. |

Message content is projected via plain `<ng-content>`.

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `visibleChange` | `boolean` | `visible` changes (auto-generated by `model()`), including on self-dismiss. |

## Accessibility

- Root is `role="alert"`. The severity icon is `aria-hidden`; the close button carries `aria-label="Dismiss"`.

## Tier / dependencies

- `tier:0`. Peer dependencies: none beyond Angular core/CDK.
