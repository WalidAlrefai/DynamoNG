# @dynamong/tree-table

A hierarchical table — Tree's expand/collapse rows combined with Table's
columns — for hierarchical data where each row also carries multiple
fields, not just a label.

## Usage

```html
<dg-tree-table
  [items]="items"
  [columns]="columns"
  [(expandedIds)]="expanded"
  [loading]="isFetching()"
/>
```

```ts
protected readonly columns: DynamoTreeTableColumn<FileEntry>[] = [
  { field: 'name', header: 'Name', sortable: true },
  { field: 'size', header: 'Size' },
];
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `items` | `DynamoTreeTableNode<TRow>[]` (required) | — | Each node wraps the row's `data` plus recursive `children`. |
| `columns` | `DynamoTreeTableColumn<TRow>[]` (required) | — | |
| `expandedIds` | `string[]` (model) | `[]` | |
| `ariaLabel` | `string \| undefined` | `undefined` | |
| `emptyMessage` | `string` | `'No data'` | |
| `loading` | `boolean` | `false` | Renders a spinner + message in the empty-state slot and makes sorting, expand/collapse, and row navigation non-interactive. |
| `loadingMessage` | `string` | `'Loading…'` | Shown in the empty-state slot instead of `emptyMessage` while `loading` is true. |

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `expandedIdsChange` | `string[]` | `expandedIds` changes (auto-generated by `model()`). |

No row-selection concept exists in v1 — there is no `selectable`/`selected` model and consequently no `itemSelect` output (unlike `@dynamong/table`/`@dynamong/tree`). Adding one is tracked as a separate future feature, not a small addition, since it needs a selection model built from scratch first.

## Accessibility

- `role="treegrid"` root, `role="row"` on every `<tr>` (header included), `role="gridcell"` on every `<td>`, with `aria-level`/`aria-expanded` on data rows — the row-navigation-only treegrid variant (matching Tree's own keyboard model), not full 2D cell navigation.
- Keyboard: `ArrowDown`/`ArrowUp` move, `ArrowRight` expands (or moves into the first child), `ArrowLeft` collapses (or moves to the parent), `Home`/`End` jump, `Enter`/`Space` toggles expansion on a branch row.

## Tier / dependencies

- `tier:1` — composes `@dynamong/spinner` (`tier:0`) for its `loading` empty-state. Sort/filter-shaped logic is independently duplicated from `@dynamong/table` rather than imported (adapted for per-level recursive sort, and Table's helpers aren't exported from its own `index.ts` regardless).

## Running unit tests

Run `nx test data-tree-table` to execute the unit tests.
