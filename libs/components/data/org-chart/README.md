# @dynamong/org-chart

A top-down hierarchy diagram: each node is a box, its children sit in a
connected row beneath it — for reporting lines, taxonomies, and other
tree-shaped data better read horizontally than indented.

## Usage

```html
<dg-org-chart
  [value]="chart"
  [(collapsedIds)]="collapsed"
  [selectable]="true"
  [(selection)]="selectedIds"
  ariaLabel="Company structure"
  (nodeSelect)="onNodeSelect($event)"
>
  <ng-template let-node>
    <strong>{{ node.label }}</strong>
  </ng-template>
</dg-org-chart>
```

```ts
protected onNodeSelect(node: DynamoOrgChartNode): void { ... }
```

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `value` | `DynamoOrgChartNode[]` (required) | — | Root nodes — usually one, but a forest is allowed. Each node's `id` must be unique across the whole chart. |
| `collapsible` | `boolean` | `true` | Shows a collapse/expand toggle on every node that has children. |
| `collapsedIds` | `string[]` (model) | `[]` | Ids of currently-collapsed subtrees. Empty means the whole chart is expanded. |
| `selectable` | `boolean` | `false` | |
| `selectionMode` | `DynamoOrgChartSelectionMode` | `'single'` | `'single' \| 'multiple'`. |
| `selection` | `string[]` (model) | `[]` | Ids of selected nodes. |
| `ariaLabel` | `string \| undefined` | `undefined` | |

An optional projected `<ng-template let-node>` (`contentChild`, not required)
supplies each node's contents; with none projected, `node.label` renders as
plain text.

## Outputs

| Output | Payload | Fires when |
|---|---|---|
| `collapsedIdsChange` | `string[]` | `collapsedIds` changes (auto-generated by `model()`). |
| `selectionChange` | `string[]` | `selection` changes. |
| `nodeSelect` | `DynamoOrgChartNode` | Every node-box click, whether or not `selectable` is set. |

## Accessibility

- `role="tree"` root with `aria-label`; each node box is `role="treeitem"` with `aria-expanded` (when it has children) and `aria-selected` (when `selectable`); child groups are `role="group"`.
- Keyboard: nodes are focusable (`tabindex="0"`) when selectable or expandable. `Enter`/`Space` selects; `ArrowRight` expands a collapsed node; `ArrowLeft` collapses an expanded one.

## Tier / dependencies

- `tier:0`. Peer dependencies: none beyond Angular core/CDK.
